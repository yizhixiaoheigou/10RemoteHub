# 10RemoteHub macOS 安装说明

> 发布包位于 [GitHub Releases](https://github.com/yizhixiaoheigou/10RemoteHub/releases)。先核对同一版本的 SHA256SUMS；源码开发环境见 [RELEASE.md](RELEASE.md)。

## 需要准备

- macOS 14 或更新版本。Apple 芯片选择 `-arm64` 的发布包。Intel 对应 `-x86_64`；由于没有 Intel Mac，本轮未做 Intel 真机测试，不承诺其硬件兼容性，仅在发布页确有对应包时使用。两种架构不能混用。
- 一只讯飞 2.4G 语音遥控器，以及它随附的 0416:0602 USB 接收器（插在电脑上）。
- 安装系统组件和虚拟麦克风时，需要输入一次开机密码。

## 一、安装主程序

1. 打开下载的 `10RemoteHub-<版本>-<构建号>-arm64.dmg`（Intel 用 `-x86_64.dmg`），把 `10RemoteHub.app` 拖进「应用程序」。下载的是 zip 时，解压后同样拖进去。
2. 第一次双击时，系统会拦下来，提示「无法验证开发者」或「Apple 无法验证此 App 是否包含恶意软件」。这是预期行为：本软件使用项目自制的免费签名证书，没有向 Apple 付费购买开发者证书，也没有做公证。
3. 打开「系统设置 → 隐私与安全性」，向下滚动到「安全性」区域，会看到关于 10RemoteHub 的提示。点「仍要打开」，输入开机密码。
4. 再双击 `10RemoteHub.app`，在弹窗里点一次「打开」。以后正常启动不再需要这一步。

> 不同 macOS 版本按钮文字略有差别（「仍要打开」或「打开」）。如果系统设置里没看到提示，先双击一次应用让它出现。

## 二、跟着引导走

第一次打开会弹出一个三步引导：

1. **装读取组件**——点「安装」，输入一次管理员密码。装好后状态变成「已安装」。
2. **授权辅助功能**——点「去授权」，在系统设置里打开开关。
3. **去按键映射**——关闭引导，开始给按键分配动作。

引导只出现一次；以后想重看，菜单栏图标 →「重新运行新手引导…」。

## 三、手动授权（可选）

- 启动后进入「通用设置 → 权限」，点「辅助功能」这一行的「前往授权」。系统设置会打开，同时主窗口自动最小化（避免挡住列表），并出现一个小引导面板：把面板里的 10RemoteHub 图标拖到系统设置列表里，或点「＋」添加。
- 拖进去后在列表里打开开关。开关打开后回到应用，点「重新检测」。
- 输入监控不需要授权。这款接收器由采集组件以管理员权限直接读取，不经过系统的输入监听。
- 第一次用遥控器麦克风时，系统会询问麦克风权限，点「允许」。

## 四、安装系统组件

- 「通用设置 → 统一采集组件」→ 立即安装，输入管理员密码。装好后状态从「未安装」变为「已连接」，此时按键才会工作。
- 只用电脑麦克风时，不需要安装虚拟麦克风。
- 要用遥控器麦克风时，到「语音设置 → 虚拟麦克风」安装。安装过程会重启系统音频服务，声音和录音会中断一两秒，请先暂停通话或录音。安装器结束时会自动启用并检查，能在系统里看到「10RemoteHub Microphone」即装好。

## 五、选择麦克风

- 自动切换（默认）：识别软件里选「系统默认」或「跟随系统」。录音时自动切到虚拟麦克风，停止后恢复原来的设备。
- 固定使用虚拟麦克风：识别软件里直接选「10RemoteHub Microphone」。
- 两种方式都不会改动识别软件自己的设置，也不会一直录音。

## 六、更新到新版本

1. 从菜单栏图标退出旧版。
2. 用新版替换「应用程序」里的 `10RemoteHub.app`。
3. 打开新版。如果签名身份保持一致，权限通常可以沿用；更换签名身份或系统再次询问时，需要重新授权。
4. 采集组件或虚拟麦克风有新版本时，应用里的状态会提示，按同样步骤安装。

## 卸载

删应用不是卸载：把 `10RemoteHub.app` 拖进废纸篓，后台采集服务、虚拟麦克风和登录启动项仍留在系统里。

正确做法：点菜单栏的 10RemoteHub 图标 →「卸载 10RemoteHub…」，确认后应用会退出并打开卸载程序（需要管理员密码）。它会把主程序、采集组件、虚拟麦克风和登录启动项一起清掉，只保留你的配置（`~/Library/Application Support/RemoteHub`）。

## 常见问题

- **提示「已损坏，无法打开」**：不能只据此判断是隔离标记。先从正式发布来源重新下载，按该版本的校验值核对文件；仍失败时保留完整提示并反馈，不直接移除安全检查。详见 [排障指南](TROUBLESHOOTING.md)。
- **按键没有反应**：「通用设置 → 权限」确认辅助功能为已授权；确认接收器插好、统一采集组件显示「已连接」。
- **系统设置的权限列表里出现两个 10RemoteHub**：删掉旧的那条（旧版签名残留），保留开关已打开的一条。
- **录音没有声音**：确认虚拟麦克风已安装、系统「声音 → 输入」里能看到「10RemoteHub Microphone」；自动切换模式下识别软件要选「系统默认」。

## 为什么会有安全提示

当前构建方式使用项目自制的「10RemoteHub」签名证书，未使用 Apple Developer ID，也未做公证。自签名不能单独证明发布者身份或软件安全；需要结合可信下载来源、发布校验值和签名校验判断。签名身份一致有助于沿用系统权限，但不能保证每次更新都无需重新授权。系统提示的区别和处理方式见 [Apple 官方说明](https://support.apple.com/en-au/102445)。
