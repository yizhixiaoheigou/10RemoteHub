macOS Audio Server Plug-in
  Based on Apple's Creating an Audio Server Driver Plug-in sample (2024).
  Source: https://developer.apple.com/documentation/coreaudio/creating-an-audio-server-driver-plug-in
  Download: https://docs-assets.developer.apple.com/published/430ad6501f6f/CreatingAnAudioServerDriverPlugIn.zip
  Full permission notice: native/macos-audio/LICENSE.txt
  Modifications: timestamped loopback, device identity, default sample rate,
  input latency reporting, timestamp catch-up. Illustrative sample control
  objects are retained; audio gain/filtering is performed in the application.

  PyInstaller: https://pyinstaller.org/ (GPL with bootloader exception)
  NumPy: https://numpy.org/ (BSD)

  PyObjC: https://github.com/ronaldoussoren/pyobjc (MIT)

  Release builds must also ship the full LGPL texts plus source/relinking
  information for LGPL components (Qt/PySide6, pynput and bundled FFmpeg).
  Release gates require an exact-version license and source inventory.
  Old artifacts are not evidence of a complete compliant release.

Built-in audio decoder
  remotehub/codec is derived from FFmpeg n8.0 libavcodec/siren.c.
  Copyright (c) 2012 Youness Alaoui, 2018 Paul B Mahol, 2019 Lynne.
  Python port, receiver compatibility and synthesis changes: 10RemoteHub contributors.
  License: LGPL-2.1-or-later; full text in remotehub/codec/COPYING.LGPLv2.1.
  Source/provenance: remotehub/codec/NOTICE.md.
  Frozen builds include complete modified codec source and license in codec-source/.
  The App does not need or bundle libicocodec.so, libg7221, Unicorn or pyelftools.
  The old vendor-emulation module remains only as an excluded historical experiment.

No BlackHole source or binaries are bundled in this implementation.

Windows setup components (installed by the user, never redistributed)
  Zadig: https://zadig.akeo.ie/ (GPLv3; used once to bind the receiver's
    interfaces 3 and 4 to WinUSB). Not shipped with this project.
  VB-CABLE: https://vb-audio.com/Cable/ (VB-Audio virtual audio driver;
    freeware). Provides the virtual microphone because Windows kernel audio
    drivers must be Microsoft-signed. Not shipped with this project.
  The application itself contains no Windows kernel driver.
