# 10RemoteHub 排障指南

以下主要适用于 macOS；Windows 驱动、语音与日志排查见 [Windows 安装说明](INSTALL-Windows.md)。本次审计后的新安装包尚未发布，历史包不代表此次修复已交付。

菜单栏图标是灰的，说明现在没有连上遥控器；打开「通用设置」看「统一采集组件」这一行的状态，多数问题看这里就能定位。

## 安装时被 macOS 拦下

**现象**：双击后提示「无法验证开发者」「Apple 无法验证此 App 是否包含恶意软件」，或提示「已损坏，无法打开」。

前两种是正常的：本软件用项目自制的签名证书，没有购买 Apple 开发者证书。

1. 打开「系统设置 → 隐私与安全性」，滚动到「安全性」区域，点 10RemoteHub 旁边的「仍要打开」，输入开机密码；
2. 再双击一次应用，在弹窗里点「打开」。

如果是「已损坏，无法打开」，还可能涉及文件损坏、改动或签名问题，不能直接认定为隔离标记。先从正式发布来源重新下载，核对该版本提供的 SHA-256；仍失败时提供完整提示、版本和校验结果。不要直接移除隔离标记或关闭 Gatekeeper 来掩盖原因。系统提示的区别见 [Apple 官方说明](https://support.apple.com/en-au/102445)。

## 打开后找不到窗口

本应用常驻菜单栏，关掉窗口不等于退出。

- 单击菜单栏图标，选「打开主界面…」；
- 或单击 Dock 里的 10RemoteHub 图标。

## 按键没有反应

按顺序检查，四步之内基本能定位：

1. **辅助功能权限**：「通用设置 → 权限」里辅助功能是否为「已授权」。未授权时点「前往授权」，主窗口会自动最小化，把引导面板里的图标拖进系统设置列表，再打开开关。
2. **采集组件**：「通用设置 → 统一采集组件」是否为「已连接」。显示「未安装」就点安装，需要管理员密码。
3. **接收器**：确认接收器插在电脑上，换一个 USB 口再试。接收器是遥控器随附的那个，不要和其他 2.4G 接收器混用。
4. **这个键的动作**：打开映射页确认该键分配了动作，没有被清空。语音键固定用于语音，不参与普通按键映射。

四步都对还是没反应，带上日志来问（见文末）。

## 系统设置的权限列表里出现两个 10RemoteHub

旧版本用另一张证书签名，系统会当成两个应用。

删掉旧的那一条（通常没有开关或开关打不开），保留当前在用的、开关已打开的那条，然后回应用点「重新检测」。

## 按键重复触发，或按住后不松开

旧版本的采集程序在 USB 超时时会丢掉松开报文，表现为“按一下触发两次”或“一直处于按下状态”。新版已改为保留超时里实际收到的数据、所有端点并行异步读取。

更新到最新版即可。仍出现时，按文末方式提供日志。

## 语音说完没有出字

先判断是哪一段断了：

1. **识别软件在等吗**：按下语音键时，识别软件有没有进入“正在听”的状态。没有的话，是唤起键不对——到「语音设置」里重新录制识别软件的开始/结束快捷键。
2. **麦克风选对了吗**：
   - 自动切换模式：识别软件里选「系统默认」或「跟随系统」；
   - 固定模式：识别软件里选「10RemoteHub Microphone」。
3. **系统里有这个麦克风吗**：打开「系统设置 → 声音 → 输入」，看有没有 10RemoteHub Microphone。没有的话，到「语音设置 → 虚拟麦克风」重新安装（声音会中断一两秒）。
4. **电平有反应吗**：「语音设置」里的电平检测条，按住语音键说话时应该在动。不动说明音频没进来，回到第 3 步。

## 装完虚拟麦克风，声音或录音中断了

正常现象。安装器会重启系统音频服务，声音和录音会中断一两秒。先暂停通话或录音再安装。

## 电平一直是 0

- 虚拟麦克风没装或没选对（见上一条）；
- 第一次使用时系统问了麦克风权限，选了「不允许」。到「系统设置 → 隐私与安全性 → 麦克风」里打开 10RemoteHub；
- 遥控器电量不足或离接收器太远。

## 想彻底卸载

用发布页提供的卸载程序（`10RemoteHub-Uninstall.pkg`），它会：

- 退出前先确认应用已退出；
- 删除 `/Applications/10RemoteHub.app`；
- 卸载后台采集组件 `/Library/PrivilegedHelperTools/10RemoteHub`；
- 卸载虚拟麦克风 `/Library/Audio/Plug-Ins/HAL/RemoteHubAudio.driver` 并重载音频服务；
- 移除登录启动项和系统里的安装记录。

只删确认属于本项目的文件，其他内容保持原样。用户配置（按键映射、语音设置）默认保留在 `~/Library/Application Support/RemoteHub`，想连配置一起删可以自己删这个目录。

手动卸载的顺序（通常不需要）：先退出应用，再删上面三个路径，最后用 `launchctl bootout system/org.remotehub.device-helper` 卸掉后台服务。

## 反馈问题时请附上

- macOS 版本、芯片（Apple 芯片 / Intel）；
- 遥控器能不能在别的电脑上正常用；
- 日志文件：`~/Library/Application Support/RemoteHub/logs/connection.log`。

日志只记录连接事件和错误类型，**不记录按键内容、音频和识别出的文字**。
